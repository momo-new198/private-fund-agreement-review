# 时间优先检索，其次核对层级与权限

1. **时间与事实**：按拟设立、签约、募集和初次备案的时间核对届时生效的版本。日期不明时按审阅时点作初步判断并标明假设。已公布待生效的新规在明确覆盖计划时间时单列提示。核对本地文件中的生效、替代及废止条款，以确定新设基金适用的正文。
2. **层级和适用范围**：在时间筛选后区分法律、行政法规、规章、其他监管规范性文件、政策文件、协会自律规则、解释及办事材料。对同一主体、同一事项和事实条件核对上下位规则。较新的下位规定不能仅因发布时间覆盖仍有效的上位规定。证监会规章和协会细则可以在各自范围内并行，协会自律要求可以在授权框架内细化办理条件。合伙协议受强制要求约束，约定更严时还要核对其合同效力与可履行性。
3. **处理真冲突**：先查材料中明确的替代和授权例外。对可比较的同一层级规则核对发布时间、施行时间、特别适用范围及发布机关的衔接条款。新的一般规定和旧的特别规定无法协调时，列出两种可能结论及实际影响，标记待核实。协会规则的新旧关系查其修订、废止和过渡文件。
4. **输出依据链**：记录双方文件、条款、制定机关、适用时间、是否真冲突及理由。只使用用户提供的材料。合同效力、监管风险和备案可行性分别论证，缺少独立的效力依据时将效力问题列为待核实。

## 新设基金常见的规则交叉

| 审核场景 | 判断 |
|---|---|
| 合伙型基金聘用管理人 | SRC-0028 合同指引3号第五项（七）与 SRC-0046 第34条、SRC-0043 备案指引2号第12条并读。按基金类型核对管理人与执行事务合伙人的控制关系、管理人本身担任合伙人时的身份。SRC-0012 第7、27条适用于核对实际管理职责及投资管理转委托。 |
| 证券和股权基金的合同期限与流动性 | SRC-0043 备案指引1号第10、11条规定证券基金明确存续期和运作方式。证券基金同时看 SRC-0058 第7、25条。股权基金看 SRC-0046 第35、36条及 SRC-0043 备案指引2号，区分期限与封闭运作。 |
| 在新合同中约定未来失能和更换管理人机制 | 按 SRC-0046 第29条、SRC-0048 第4条审查召集、表决、生效、变更、提前终止和清算机制。法律或合同另有约定的情形与三分之二默认表决门槛分别判断。 |
| 新合同的披露条款 | 对2026-09-01起适用的安排，按 SRC-0021 证监会令第233号和 SRC-0013 中基协发〔2026〕11号审查。按产品类型判断报告内容、周期、审计和送达。 |
| 2026 年私募监管指导意见与募集流程 | SRC-0010 为政策文件。按其具体事项核对已提供的配套生效规定。2016 募集规则第30、31条的回访实施要同时核对 SRC-0024 发布通知中的另行通知安排及合同承诺。缺少后续正式通知时保留实施状态。 |
| 暂行办法与私募条例 | 核对 SRC-0059 证监会令第105号相关条款与 SRC-0012 国务院令第762号及产品专项规则能否同时适用。例如合格投资者门槛、首次实缴和豁免须分别判断。 |

## 法规正文、附件及适用口径的差异

|两组文字|适用判断及操作|
|---|---|
|合伙企业法13/90条15日；市场主体登记条例30日相关规定|先检查新日期，再核上位及特别规则。不能直接把新设合伙协议中所有15日改30日；按具体变更/注销事项记录法源，登记行政办理与企业内部决议分开|
|2026细则13条“超过”10%/25%；同日证券模板脚注“及以上”|属于正文与模板边界差异，不是日期替代。相等时说明填报依据，采用充分披露可作操作建议；不把原文改成达到或武断称已违反正文|
|股权半年模板DPI/TVPI选填且退出期；年度未标选填及细则指标列项|按指标、报告期、基金阶段分别核，列明差异，不能一律可选或一律自始强制|
|细则50条备份处罚错引42条；义务实际在43条|不篡改引文；义务引用43条，处罚说明50条原文引条差异，不自行创造处罚条款|
|募集办法13条监督协议；起草说明同机构豁免；后续材料清单替代材料|SRC44第9项、45第13项明确同机构防火墙和防范利益冲突制度路径。材料办理与实体职责分别结论，不仅凭说明免全部监督|
|2016合同指引1号22条可多管理人；2023登记备案办法30条不得超过一家|对新设基金使用后续一管理人规则；旧指引其他未冲突条款继续按适用范围使用|
|合同指引十年档案；后续披露办法/细则二十年|先确认相同资料类型及保存起点。旧十年不能降低后法同范围二十年要求，不把所有资料无差别套同一起算日|
|备案指引2号17条上层全体一致同意；材料清单签章栏合同约定比例|实质同意条件以正文为依据，签章说明不独自放宽上层全体一致要求；记录文本差异及适用其他例外的事实|

以上差异对应精确位置及双侧影响见[监管规则细目](监管规则细目.md)。不借“时间优先”把较新案例、说明或政策工作任务当作自动废止现行法律的依据。
