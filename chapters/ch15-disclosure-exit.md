# Chapter 15: 披露、审计与未来失能退出

## Core Idea
新基金合同须写清可执行的披露和未来失能机制。2026年披露新规已纳入本地库，成熟样本的日期、保密编辑权和送达安排也必须重新过规则。

## Questions This Chapter Answers
- 半年、年度、重大事项报告分别何时发，审计要求是什么？
- 保密、备份、网站公告能否替代向投资者披露？
- 管理人失联后谁召集、谁交接，三分之二是否不可变更？

## Rules & Thresholds
来源：SRC-0021证监会令第233号，2026-09-01施行；SRC-0013中基协发〔2026〕11号，同日施行并废止旧2016披露办法。细则为自律规则，证监会办法为部门规章，分别标注。

|产品/事项|要求及定位|
|---|---|
|证券定期|办法第18—21条：开放净值频率不低于开放频率，封闭至少季度；季报季度结束起1个月，年报年度结束起4个月；专项审计条件另核|
|股权定期|办法第22—24条、细则第23、32—36条：每半年结束起2个月（包括下半年，不以年报当然替代），年度结束起6个月；年度财务报表审计。细则第36条基金规模超过1亿元且自然人投资者不少于20人，须符合证券法规定的会计师事务所等条件|
|创投|办法第25条、细则第37条：年度披露适用股权年度要求，半年鼓励。不能强称全部创投必须半年报告；合同自愿承诺另需履行|
|成立不足3个月|办法第26条可不编当期季度/半年度/年度报告，核成立日期与具体报告期；不免除重大事项及已作合同承诺|
|证券特别审计|细则第22条按年末核：流动性受限资产+新三板（排除私募基金及衍生品）高于NAV60%；衍生品合约价值高于NAV60%或账户权益高于NAV20%；境外资产高于NAV60%（直接投境外标准化资产除外）；其他证券管理人管理的私募基金高于NAV60%；上述相关金额及衍生品持仓合约价值混合高于NAV60%也核。不能误写为达到60%或将账户权益写成账户资产|
|重大事项|办法第27条发生起5个工作日内向投资者披露，逐项核列举事项及实质影响；不能只写“及时”且无执行安排|
|穿透|细则第28—29条核SPV项目详情、FOF前十大底层项目；90%以上投同一基金的，按第29、41条提供底层定期/重大/清算信息，不仅汇总本层NAV|
|审计完整|细则第33条披露完整审计报告，不得编辑或删减审计意见；不能以样本保密权覆盖|
|清算|办法第29条、细则第39条核每次清算报告、延期及超过1年至少每年披露；未托管最终清算审计及约定例外核正文|
|送达、备份、档案|办法第8、10、34条及细则第43、45条：约定具体披露方式，网站须特定对象访问，备份不替代披露；终止清算后保存不少于20年|

## Worked Example
例如，某协议把半年报告期限写为半年结束后三个月，并笼统约定遵守后续生效的规则。若用于2026年9月后新设的非创投股权基金并无不足3个月例外，半年结束后2个月应至8月底，具体期限仍需修订；一般从法条款不能替代消除正文冲突。SRC-0021第22条、SRC-0013第23条是对应依据。

如协议允许编辑敏感内容并引用旧披露办法，应核对披露权限与规则版本。应明确保密仅影响依法可调整的表达及受限送达，不减少法定内容、不删审计意见；更新适用引用。仅提供公开网址不能证明合规送达，还需访问控制、通知、可获取与留痕事实。商业上可约定提前报告、更细项目进展、查账流程，但不得削弱法定知情权。

## Future Manager Failure
SRC-0046第29条、SRC-0048《私募投资基金备案指引第3号——私募投资基金变更管理人（2025年修订）》第4—8、13—14条：
1. 新合同先约定召集、表决、生效、变更、提前终止和清算；管理人失能时给予投资者可操作的召集权。
2. 第4条的三分之二是无法律或合同另约时的默认门槛，不写成不可调整的强制比例。表决分母和利益冲突另写清。
3. 分开GP除名、管理人更换与基金终止；替代管理人条件、10工作日报送、原管理人无法配合时新管理人报送及证明要求按第5—7条查。全体投资者一致同意情形与公证/法律意见要求的例外核原文。
4. 协会办理变更不裁判合同权利效力；争议处理与业务变更不要互相替代。专业机构临时组织/清算不当然算管理人变更。

## Key Takeaways
成熟样本需要新设时点校验。监管最低披露、额外商业信息、保密保护分别写；新合同的未来处置机制属于审阅范围，存续基金如何适配新规则不在范围。

## 正文、模板和说明的差异
六份重要内容模板也是本地自律资料，不能一律当可选市场模板。细则第13条为同债券超过10%/同资产超过25%，证券季/年模板脚注45/46为10%/25%及以上；相等时应列模板填报口径及正文差异，不能伪引正文为“达到”。股权半年度模板DPI/TVPI标选填且限退出期，年度未标选填但仍有退出期脚注；与细则列项逐一联读，不能统称全部可省略。细则第50条把备份义务错引第42条，实际义务在第43条：保留原引文，另注差异。更多分母、穿透和脚注要求见[ch18](ch18-detailed-rules.md)。
