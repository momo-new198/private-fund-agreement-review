# Chapter 1: 出资比例、项目参与比例与费用亏损

## Core Idea
认缴、实缴、可用资本和投资成本分摊比例解决不同问题。一个比例贯穿所有条款，遇到费用减免、排除、后续募集或违约时可能错误转移经济利益。
来源：律所手册。商业方法，监管限制另查适用规则。

## Questions This Chapter Answers
- 费率优惠后，LP是否应多参与项目？
- 投资豁免后如何分配费用、收益及亏损？
- 单一项目基金先确定底层投资额还是先确定认缴额？

## Frameworks Introduced
- **可用资本**：按需提款时一般为认缴余额；按期缴款时还包括已实缴未使用余额。核对循环投资、返还未用出资、违约缩减怎样恢复或减少余额，避免重复计算。
- **投资成本分摊比例（Sharing Percentage / Partnership Percentage）**：在每次投资前，先确定有资格参加的投资者，再按其可用于该项目的资本分摊成本；将比例固化到该项目台账。后续项目重新核算，不能拿当前基金认缴比例重写已退出项目。
- **单一项目的倒算模式/正算模式**：底层额度确定时，由成本+费用+管理费倒算承诺额；承诺额已确定时，扣除费用预留后正算底层投资额。管理费以实缴额为基数可能产生循环计算，应解方程或迭代验证，不可只预留一次费用。

## Reference Tables
|事项|手册的方法|需明确的选择|
|---|---|---|
|项目投资、项目费用、项目损失|该项目参与比例|受排除者是否承担此前已发生费用|
|非项目费用及相应损失|一般按认缴比例|基金整体事项、特别归属于某LP事项分别处理|
|收益初步划分|与产生收益的项目参与一致|后续交割追溯调整范围|
|表决|按有效法律及合同确定|不能由经济比例自动推导法定表决比例|
|外部责任|LP法定责任边界|不能把责任限额误读为内部亏损分摊比例|

## Worked Example
手册：A、B、C实缴均100，费用分别2、1、0；如优惠留在基金并用于项目，项目可用额为98、99、100。如果合同选择优惠不影响参与比例，则应明确优惠未缴/返还及视同核算规则。

A、B可用额98、99，X需40，分摊40×98/197≈19.9、40×99/197≈20.1。Y需60且A被排除，则B承担60；Z需10时，剩余约78.1和18.9，分摊约8和2。原图中的78.1、78.9为展示用舍入，实际台账保留精度。

手册单项目倒算：A底层成本200、B300，总非管理费用80；成本比例40%/60%。五年管理费分别为底层成本每年1%/2%，费用分别32/48、管理费10/30，预计需242/378；不能据此把底层权益变成242∶378。若另留余量，须说明用途和返还。

## Anti-patterns
- 只改“优惠费率”，仍按统一实缴比例分配全部回款。
- 将未使用资本、项目已返本金额、可再提款承诺混在同一个“本金”定义。
- 把LP有限责任误解为必须按认缴比例分摊每项亏损。

## Key Takeaways
1. 审阅时列出每个分母、时点、参与者、调整事由，并与资金使用一致核对。
2. LP侧要求优惠落到本人、排除不承担不相关损失；GP侧保留合理调整权但要求可复核台账；中立说明准确性与运营成本取舍。
3. 修改比例定义后同步修改提款、费用、分配、违约及后续募集。连接[ch07](ch07-fees.md)、[ch08](ch08-closing.md)。

## 单项目预算的边界
律所手册：单项目通常不设投资排除，GP也未必参与投资及成本；逐一确认参加者。242/378是所列假设下预计所需金额，未含额外预算余量。另一种方案以252/378认缴但优惠LP实际少缴10，不能因此误写其欠缴或降低底层200/300权益。价内/价外费用、备用金与费用实缴循环须同时建模，不把样例数字当统一最低出资额。
