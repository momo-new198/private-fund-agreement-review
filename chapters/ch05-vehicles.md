# Chapter 5: 平行、联接、替代、联合投资及SPV

## Core Idea
先画出谁募集、谁出资、谁投资、谁收费用的路径，再决定备案、嵌套、经济核算和表决安排。来源：律所手册，五张架构图已核看。手册提及而本地未收录的处罚决定或其他规定不能独立支撑监管结论。

## Questions This Chapter Answers
- 同一GP管理多个载体时如何分配机会和费用？
- 联接基金中一人违约是否应处罚所有人？
- No Fee No Carry或“SPV”名称是否等于无需备案？

## Reference Tables
|载体|经济功能|必须落实的商业事项|
|---|---|---|
|平行基金 Parallel Fund|同一期、近似策略并行投资|按认缴/可用资本/固定比例分机会；调整已投比例的实施办法；共同费用与专属费用；共同事项和专属事项表决区分|
|联接基金 Feeder Fund|汇集投资者投主基金|扣除本层费用后的净投资额；表决传递；优惠、违约和分配的穿透核算|
|替代载体 AIV|主基金或部分LP受限制时替代投资|适用理由、参与者、文件实质一致性、已缴额抵主基金承诺；避免新增总出资负担|
|联合投资载体 Co-investment Vehicle|基金与其他投资方共同投项目|剩余额度、费用及退出协调；若实质另行募资，应按事实审查是否构成基金|
|SPV|基金下层持有项目|实际募资、控制、收费、账户及托管监督；Warehouse转入项目的定价和冲突|

## Frameworks Introduced
1. 对每层列出资金来源、投资者、管理者、法律形式、控制关系、总承诺和费用。
2. 逐项目确定共同成本、专属成本、后续追加、退出同步与不能同步时的处理。
3. 将两层优惠、违约责任和投票传导到最终相关投资者；合同穿透核算不能直接替代监管穿透认定。
4. 按SRC-0012第25条、SRC-0043备案指引2号第4、10、21条等核对嵌套、人数、内部投资单元、SPV托管；未收录的豁免文件须列资料缺口。

## Worked Example
手册：联接基金收1元后自身还需审计等费用，不能承诺对主基金也净投1元。若其中一名LP未缴，应在文件支持的范围内将违约责任归于该人，避免全部守约LP被主基金一起处罚。此机制需要主基金和联接文件配套，仅写联接内部协议不足。

## Common Misreadings
- 无管理费或carry就自动非基金；管理人相同就可以混同资金或跨基金补贴。
- 把“投资排除”用作允许LP自主挑项目的内部单元，或认为账面排除当然满足投资者自身行业限制。
- AIV抵减承诺后未改原基金提款和费用基数，导致双重缴款。

## Key Takeaways
1. GP侧需要架构灵活性；LP侧需要总承诺、总费用与冲突边界；中立保证每一层权责和现金流闭合。
2. 载体合并核算、合并表决不等于合并法律人格或税基。
3. 境外制度比较不用于在本技能中给出境外适用结论。


## 本地最新嵌套案例校验
SRC-0033总第5期（2026-10-21）第5—9页案例3-1至3-4，结合SRC-0012第25条：从最上层投资者逐条画到标的，不能只检查本基金以下。创投/政府基金名称本身不自动豁免；案例3-2要求核“接受其他基金/资管投资”的条件；案例3-3同一路径多只创投最多豁免一次，多只政府基金最多一次，同时两类最多各一次。案例3-4明确当时母基金配套规则尚未正式实施，不能凭“主要投其他基金”直接不计层级。该动态引用的资管新规、1638号正文未单独收录，完整豁免条件须补正文，不由案例推导任意架构均可备案。标注协会案例口径，不冒称其本身为法律。

## 跨载体的五项落地检查
律所手册；以下执行顺序为归纳(inference)。
1. 平行基金：项目费用按项目参与、共同费用按约定规模比例、专属费用独立承担；违约金与后续募集补偿是本层归属还是多基金合并，明确写出。合并carry不当然允许跨主体税基抵扣，合并表决仍须各法律主体完成程序。
2. 比例变化：后续交割、违约、投资排除发生时，同时检查主基金、平行基金及共同SPV的比例调整、转让成本、税费及同意机制，不能仅改一个台账。
3. 联接：本层先预留自身费用；穿透违约和表决必须有两层文件支持，并保留守约投资者权益。监管穿透条件单独判断。
4. AIV：实际缴付是否抵减原基金未缴承诺、费用是否抵扣，须分别列数；原LPA概括授权不当然代替新主体所需的有效签署、开户与决议。
5. Warehouse：先行持有后转给基金的，核权属、转让时间、成本/估值、收益归属及关联程序；No Fee No Carry不当然免备案。
