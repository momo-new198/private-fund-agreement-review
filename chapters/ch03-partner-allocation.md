# Chapter 3: All Partners与By Partner

## Core Idea
先共同分层还是先逐人划分，是独立于整体/按项目返本的另一个维度。来源：律所手册。

## Questions This Chapter Answers
- 费用或carry有个别优惠时怎样避免其他投资者分享？
- GP先拿出资收益再拿carry是否重复收费？
- All Partners条款为什么会漏算GP收益？

## Frameworks Introduced
- **All Partners模式**：先按本金、门槛、追补、剩余分成分层，各层再在当事人之间划分。适用于经济安排较统一、希望简化核算的基金。
- **Partner By Partner（By Partner）模式**：先按项目参与比例将可分配款初分到每人，GP自投部分按约取得，各LP部分分别适用与GP之间的瀑布。适合费率优惠、排除、违约和carry比例不同的情况。
- 先确认交易意图，再判断缺失。手册的等价比较以GP实缴与LP实缴享有相同投资收益为前提；合同有意让GP让利时不能强行改为等价。

## Worked Example
手册：GP100、LP400；一年回款600、8%门槛、20%carry且全额追补。
By Partner：先分GP120、LP480；LP池内返本400、门槛32、追补8给GP，余40分GP8/LP32，终值GP136、LP464。
All Partners：返本100/400，门槛8/32，追补(8+32)×20%/80%=10给GP；余50中carry10给GP，其余40按1∶4分8/32。终值同为136/464。
因此既不能将GP自投收益与carry混为一谈，也不能仅凭模式名称认定GP多拿。

## Anti-patterns
- All Partners只追补LP门槛，且最终80%只给LP，却声称等同于GP自投平等待遇。
- 给一个LP减费后，仍从全基金总回款扣总费用并统一按比例分，导致优惠外溢。
- 从共同池扣单个LP违约金，导致守约者承担处罚。
- 用By Partner名义设内部投资单元，使投资者任意选项目；经济核算与合规投资排除不是任意选项目的授权。

## Key Takeaways
1. 审核报告先标明“返本维度×投资者维度”两个结论。
2. 逐人核对初分、扣费、门槛、carry、回拨；检查合计与基金现金守恒。
3. GP侧应能解释两种身份的收入；LP侧应能复算个别条件；中立选择可实际执行的核算方式。
