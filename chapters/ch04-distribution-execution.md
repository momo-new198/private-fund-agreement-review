# Chapter 4: 收入分类、LP回拨与非现金分配

## Core Idea
不能把基金账户内所有资金都当作项目收益，统一套同一瀑布。来源：律所手册。

## Questions This Chapter Answers
- 预缴资金的利息和项目退出后的闲置利息分别归谁？
- LP收到分配后还可能承担哪些返还义务？
- 怎样约定非现金分配才可执行？

## Reference Tables
|资金|先核归属|再核计算|
|---|---|---|
|投资退出、分红|该项目参与者|成本比例→对应瀑布|
|未用出资的现金管理收益|产生该收益的出资及占用期间|避免迟缴者无差别分享|
|项目回款等待分配期间收益|对应项目参与者|可与该项目回款同口径|
|违约金|按约受损或守约投资者|两个LP先后违约时，不能仅凭最终实缴额让补缴者分享全部惩罚款|
|特定投资者税收返还等|产生该收入的投资者|不能未经核对共同分摊|
|未使用出资|实际尚未使用者|是否恢复承诺、进入返本累计、影响门槛需分别约定|
|后续募集补偿|被垫付者/晚收费用者|读[ch08](ch08-closing.md)|

## Frameworks Introduced
- **LP回拨（LP Clawback）**：用于基金后续责任、补偿或差额调整的返还，与GP超收carry回拨分开。核对用途、已分配额或净税后额上限、起算点、期限、通知、争议处理、未来分配抵扣。不得把合同回拨上限写成排除一切法定责任。
- **非现金分配**：明确可分配资产、触发条件、谁批准、估值日与方法、变现选择及成本。需结合投资者持有资格、交易限制、锁定和过户条件；后几项是执行层面的本轮归纳（inference）。

## Worked Example
手册：A、B各实缴100，A已全用，B因投资排除剩余80。返还未用80应定向给B，不能按实缴各给40。另应判断B未用额是否继续参与收益、是否恢复提款义务；这是分别的合同选择。

## Key Takeaways
1. 分配时间要兼顾投资者及时回款、管理人降低门槛累积和实际核算程序；设合理准备金和说明义务。
2. LP侧限制无上限无限期返还、难变现资产强塞；GP侧保留清偿和退出所需机制；中立明确谁承担税费和流动性风险。
3. 手册关于短期过桥收益的分类是商业记账方法，不等于该项借款合法。
