# Chapter 18: 全文规则的条件、脚注与专项入口

## Core Idea
规则正文、附件模板、起草说明、案例动态和政策部署各有用途；每项结论都连到具体主体、产品、行为、分母、时点及例外。按审阅事项查[文件索引](../references/文件索引.csv)和[监管规则细目](../references/监管规则细目.md)，并核对对应原文。

## Questions This Chapter Answers
- 一样写90%或6个月，能否合并成一条普遍规则？
- 监管附件中的选填、脚注与正文不一致怎样判断？
- 基金成立、募集失败、证券操作及治理条款还有哪些容易遗漏的条件？

## 披露内容与数据取得
来源SRC-0013、0014—0019、0021；细则/模板为自律，办法为部门规章。

## 募集、文件与组织形式
1. SRC-0024第32条分两组豁免：五类列明主体可免17—21、26—31条；专业投资机构只免29—31条。“专业投资者”标签不自动等于任一组。逐步骤列保留义务。
2. SRC-0026风险揭示附件募集失败：管理人固有财产承担募集债费；募集期届满确认不能成立后30日内返还款项并加同期存款利息。标明协会附件性质，与当期其他规则、认购及LPA同时核，不把失败费用无限扣投资款。
3. SRC-0027起草说明允许特定同一金融机构兼任时免账户监督协议，SRC-0024第13条正文未明载该豁免；SRC-0044第9项、SRC-0045第13项另有实际材料路径：不同机构提交监督协议，同机构提交防火墙及防范利益冲突制度，多个募集机构提交全部相关协议。分别标明正文、解释和材料依据；替代材料不免除资金监督和责任。
4. SRC-0028指引1号第22条历史多管理人许可与SRC-0046第30条“私募基金的管理人不得超过一家”冲突，新设按后规则；这是版本适用，不研究存续基金改造。
5. 契约型依SRC-0028指引1号第23条，运作期间聘换投顾或调报酬经持有人大会同意，管理人不免责；43条排除不履职造成损失及非基金费用。公司/合伙须核自身规则，不机械套用该唯一表决方式。
6. 合伙型依指引3号第五项（五）（十），核八类非执行行为、实际委员会职能，以及投资范围/方式/限制/决策/关联/投后/风险/退出/担保措施/举债限制。公司型依指引2号及公司法分别核股东会、董事会、利润、资本及账簿。

## 产品、主体与政策精确适用
- **期限错配**：SRC-0043指引2号17条、SRC-0045材料清单。原文限制本基金“早于下层…到期日6个月以上”“晚于上层…到期日6个月以上”的反向错配；不是上下层必须预留正向六个月。上层全体投资者一致同意等例外逐项核；材料签章栏不能独自放宽正文。恰好六个月应保留“以上”原词及起止日期，不能改成严格“大于”而擅免。
- **证券细节**：SRC-0043指引1号的临时开放、份额类别、60%业绩报酬上限及通常6月间隔，与SRC-0058运作指引的单一计提方法、流动性、杠杆、集中度分别联读；具体限定和例外见规则细目，不套股权carry参数。
- **管理人登记**：SRC-0036—0040和0046关于名称、资本、控制、从业经验及持续履职的要求，用于核实际管理者及控制链；不将管理人股东层级与基金投资嵌套混为一类。不得把工商经营范围和协会业务资格当同一许可。
- **政府与创投政策**：SRC-0009的管理费“一般应”与“鼓励降低返投”等政策语气保留；SRC-0010具体准入程序与较早文件按时间联读。“制定出台”等工作任务不是已经完成的新制度；原文“有删减”属于资料限制，不能补造未公开段落。
- **外引缺口**：税收、国资、资管新规及特定人员投资限制若仅手册/案例提及而无原正文，记录具体缺文件；不靠记忆或样本保证条款补成法律结论。

## Key Takeaways
1. 不把旧允许、说明豁免、政策任务或样本自由裁量变成新设基金的当然权利。
2. 强制底线、任意规范、自律要求、填报口径、政策方向及商业选项分别标识；违规、备案后果及民事效力分别论证。
3. 每批更新须全读新增文件及附件，保留差异；完整阅读记录和规则索引是两种证据，不能互相冒充。
